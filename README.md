# ⚔️ 17x17 战棋对弈系统 (17x17 Tactical Chess Engine)

![Python Version](https://img.shields.io/badge/python-3.10%2B-blue.svg)
![GUI Framework](https://img.shields.io/badge/GUI-Pygame-green.svg)

一款基于 Python 与 Pygame 开发的 **17×17 暗棋双人策略战棋游戏**。游戏结合了**非对称信息（暗棋机制）**、**丰富兵种协同**、**地形战术**以及**随机天气系统**，兼具极高的策略深度与不确定性。

## ✨ 核心特色

1. **暗棋迷雾（隐藏信息机制）：**
   - 棋子初始均为背面朝上（`UNKNOWN` 状态），对方无法得知具体兵种。
   - 移动过程不公开身份；只有在发生**击杀、被攻击或触发陷阱**时才会翻面曝光。
2. **多样化兵种搭配：**
   - 拥有 **骑士、刺客、盾卫、弓手、法师、猎手、主帅** 7 种职能各异的棋子。
   - 包含**潜伏（刺客）**、**盾牌抵挡/退敌（盾卫）**、**长程射击（弓手）**、**射线贯穿（法师）**、**隐蔽陷阱（猎手）** 等特色能力。
3. **高策略性地图地形：**
   - 包含平地、河流、桥梁、草丛等多种地形。
   - 活用草丛躲避弓手视线或为刺客提供无消耗潜行步数；抓住桥梁隘口实行一夫当关。
4. **动态天气系统（扩展玩法）：**
   - 包含炎热、迷雾、凌寒（湖面结冰/破冰陷阱）、谷雨、水灾、蝗灾、暮春等多种天气，动态改变战场格局。

## 🛠️ 项目架构与模块说明

```text
.
├── chess_defs.py       # 游戏核心数据结构与枚举定义 (Owner, PieceType, Terrain, Block等)
├── game_engine.py     # 游戏核心逻辑引擎 (棋盘初始化、广度优先/深度优先路径求解、移动及技能合法性判定)
├── main.py            # 基于 Pygame 的图形界面渲染与客户端主循环 (包含可视化测试逻辑)
└── chessIco/          # 棋子图标资源目录
    ├── 1/             # 玩家 A 棋子图标 (1.png ~ 8.png)
    └── 2/             # 玩家 B 棋子图标 (1.png ~ 8.png)
```

### 核心模块职责：

- **`chess_defs.py`**
  - 使用 Python 标准库 `enum` 与 `dataclasses` 构建高性能不可变对象。
  - 定义棋子所有权 (`Owner`)、棋子类型 (`PieceType`)、地形 (`Terrain`)、陷阱所有权 (`TrapOwner`) 以及格子 (`Block`) 数据结构。
- **`game_engine.py`**
  - `init_board()`：构建 17×17 标准棋盘并生成对称地形（河流、桥梁、草丛）。
  - `get_valid_moves()`：基于 BFS / 状态搜索计算各类棋子的合法移动范围（自动处理桥梁/河流限制及第一回合不准上桥规则）。
  - `get_archer_targets()` / `get_mage_targets()` / `get_hunter_targets()`：精确求解远程攻击与能力释放的目标集合。
- **`main.py`**
  - 处理图像加载、网格绘制、观察者视点 (`viewer`) 渲染及游戏事件响应。

## 🎮 游戏规则与机制

### 1. 胜利条件
- **斩首行动：** 杀死敌方主帅 (`COMMANDER`)。
- **夺旗胜出：** 己方主帅成功占领敌方军营中心点，并持续停留 **3 轮**（3个回合结束）。

### 2. 地形系统
| 地形类型 | 可否通过 | 战术效果说明 |
| :--- | :---: | :--- |
| **平地 (PLAIN)** | ✅ 是 | 通用基础地形。 |
| **河流 (RIVER)** | ❌ 否 | 阻断通行；常规陆地棋子无法进入。 |
| **桥梁 (BRIDGE)** | ✅ 是 | 联通河流两侧的隘口（注意：**第 1 回合双方均不可上桥**）。 |
| **草丛 (GRASS)** | ✅ 是 | 弓手无法射击草丛中的目标；刺客在此可消耗潜伏值实现零步数移动。 |

### 3. 棋子兵种与技能

| 棋子兵种 | 攻击类型 | 移动 / 攻击机制 | 特殊能力 / 被动技能 |
| :--- | :---: | :--- | :--- |
| **骑士 (KNIGHT)** | 近战 | 八向直线移动，最高 9 格，不可转向。 | **长驱直入：** 直线冲锋杀敌，遇敌即止。 |
| **刺客 (ASSASSIN)** | 近战 | 八向自由移动，最高 4 格，可转向。 | **潜伏 (被动)：** 不移动时回合结束潜伏值+1(上限6)。在草丛中可消耗潜伏值代替步数。 |
| **盾卫 (SHIELD)** | 近战 | 八向自由移动，最高 2 格，可转向。 | **坚盾 (被动)：** 首次受击免疫死亡，反弹近战敌人1格并进入1回合僵直并亮牌；第二次受击死亡。 |
| **弓手 (ARCHER)** | 远程 | 八向自由移动，最高 3 格，不可走入敌敌格子。 | **精准射击 (主动)：** 耗费1回合，杀死直线7格内最近的非草丛敌人。不可连续两回合使用。 |
| **法师 (MAGE)** | 远程 | 八向自由移动，最高 2 格，不可走入敌敌格子。 | **元素射线 (主动)：** 耗费1回合，对射线3格内所有棋子施法。穿透攻击，但会被盾卫阻挡后续路线。 |
| **猎手 (HUNTER)** | 近战 | 八向自由移动，最高 3 格，可转向。 | **布设陷阱 (主动)：** 耗费1回合在周边布设隐形陷阱(最多2个)。敌方踩中时剩余步数清至1并亮牌。 |
| **主帅 (COMMANDER)**| 近战 | 八向自由移动，最高 3 格，无特殊能力。 | **核心战法：** 主帅死亡则游戏直接失败。 |

### 4. 天气模组 (扩展规则)
游戏过程中有概率触发随机天气，持续数回合，极大丰富了战局变化：
- **炎热：** 所有棋子最大移动步数 -1。
- **迷雾：** 桥上移动消耗步数翻倍；弓手无法跨河/跨桥射击。
- **凌寒：** 湖面结冰变为平地；天气结束破冰时，冰面上所有棋子直接死亡（无视盾卫被动）。
- **水灾：** 阶段性桥面被淹没视为河流，桥上棋子死亡。
- **蝗灾：** 所有草丛失效，视为普通平地。
- **暮春：** 所有棋子最大移动步数 +1。

## 🚀 快速开始

### 环境准备
- 推荐使用 Python **3.10** 或更高版本。

### 安装依赖
通过 pip 安装 Pygame 依赖库：
```bash
pip install pygame
```

### 运行游戏
直接运行主程序以启动渲染与测试逻辑：
```bash
python main.py
```
